# Multi Agent

Connecting different AI Agents

## Environment

- Package/env manager: [uv](https://docs.astral.sh/uv/) (project initialised with `uv init`)
- Virtual environment: `.venv`, prompt name `(MultiAgents)`
- Activate (PowerShell): `.venv\Scripts\Activate.ps1`
- Activate (Git Bash): `source .venv/Scripts/activate`
- Add dependencies with `uv add <pkg>`; run with `uv run <cmd>`
